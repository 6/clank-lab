# Lean proof

From this directory, with [elan](https://github.com/leanprover/elan) installed:

```sh
lake exe cache get
lake build
```

`lean-toolchain` selects Lean 4.32.2. `lake-manifest.json` fixes Mathlib v4.32.2
at commit `905b95818eb32af7874a58b427f50c1711a5e96c` and fixes its transitive
dependencies. Lake downloads them; they are not bundled here.

`StanleySnf.stanley_class_sum_snf` in `StanleySnf/Final.lean` proves, for every
$n \ge 1$, the invariant-factor formula and its divisibility order.
`StanleySnf/Defs.lean` defines the matrix directly through multiplication of
class sums in the integral group algebra. `HasStanleySNF` expresses Smith normal
form by a basis of the target lattice in which the image is generated by the
specified multiples of basis vectors. The paper explains its equivalence to the
usual diagonal-matrix definition.

`StanleySnf/Fidelity.lean` checks that the class sums contain each permutation of
the given cycle type once, that cycle type agrees with conjugacy, and that the
matrix is the multiplication matrix in this basis. `StanleySnf/Bridge.lean`
proves the class-multiplication formula used by the lattice argument.

The default build also checks `StanleySnf/Checks.lean`: the final theorem's exact
type, small values of the invariant-factor definition, and guarded axiom reports
for the theorem, the class-multiplication formula, and the definition lemmas.
The reports allow exactly `propext`, `Classical.choice`, and `Quot.sound`.
In particular, the theorem has no `sorry` dependency or additional axiom.
No additional computational checker is required.
