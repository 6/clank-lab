# Computation and certificate checks

Install Python 3, [GAP](https://www.gap-system.org/) 4.15.1 with its
`smallgrp` and `transgrp` packages, and the Python requirements. On Debian
or Ubuntu, the GAP packages are `gap-core`, `gap-libs`, `gap-smallgrp`,
and `gap-transgrp`. No CHEVIE installation is needed.

From the result directory:

```sh
python3 -m pip install -r checks/requirements.txt
python3 checks/verify.py
```

The check takes about five minutes. It requires GAP and never skips the
group computations. `--workers 1` runs the steps sequentially. The options
`--part K/8` and `--list` select or list one of eight parts for parallel CI;
omitting `--part` runs every part. Each GAP check remains whole, including
its exhaustive cover check.

A successful full check ends with:

```text
PASS weak parking full certificate replay: E7 1080; E8 3360; E6 300
```

The data contain E7 and E8 certificates and an E6 control. The two full
GAP checkers reconstruct the root systems, verify the complete noncrossing
intervals and their cyclic orbits, check the parabolic subgroups and
conjugacy-class covers, verify every class-fusion witness, and recompute
the parking character. Their character values are compared with exact
cyclotomic eigenspace dimensions. Separate Python calculations using
SymPy check rational characteristic polynomials and the q-Catalan cyclic
fixed counts. Both checkers must reject a changed character entry and a
removed descending-cover leaf with its count adjusted.

For this additional cyclic check, let $h$ be the Coxeter number and let
$d_1,\ldots,d_n$ be the invariant degrees. The polynomial used is

```math
\mathrm{Cat}_W(q)=\prod_{i=1}^n\frac{1-q^{h+d_i}}{1-q^{d_i}}.
```

The degrees are $(2,5,6,8,9,12)$ for $E_6$,
$(2,6,8,10,12,14,18)$ for $E_7$, and
$(2,8,12,14,18,20,24,30)$ for $E_8$. For every integer
$0\le d<h$, its value at $q=\exp(2\pi i d/h)$ is compared with
the number of flats fixed by $c^d$. The computation cancels the rational
expression to a polynomial and reduces it modulo the corresponding
cyclotomic polynomial, using exact rational arithmetic.

`check_certificate.g` and `independent.g` implement the full checks
separately. Neither imports the producer. Both trust GAP's exact
arithmetic, group algorithms, conjugacy tests, centralizers and linear
algebra. Python transports JSON and gzip data; SymPy supplies exact
rational polynomial arithmetic. The paper gives the mathematical
reduction and the published theorems used by these computations.

To regenerate all certificates in a separate directory and check them:

```sh
python3 checks/replay.py produce --data /tmp/weak-parking --ranks 6 7 8
python3 checks/verify.py --data /tmp/weak-parking
```

`producer.g` enumerates the noncrossing interval by reflection descents,
groups its elements into Coxeter orbits, and constructs the conjugacy
and fusion witnesses used in the certificates. Its numerical answers
are checked by the commands above. GAP versions may choose different
conjugacy-class representatives; the checks verify their mathematical
content without requiring an ordering or compressed-byte identity.
The optional `python3 checks/replay.py direct-e6` repeats the E6 control
by enumerating every group element and each pointwise stabilizer directly;
it is slower and is not required for the certificate check.

Each result JSON contains the rank, Coxeter number, group order, root
count, noncrossing count, orbit count, conjugacy-class sizes and orders,
representative matrices, and character table. Each compressed certificate
contains the rank, descending-parent pairs, cyclic-orbit pairs, and
subgroup conjugacy-class rows with fusion witnesses. Root indices refer
to the lexicographically sorted roots generated by the displayed E-type
Cartan matrix. All stored numerical values in these JSON files are
integers; the checks also use exact rational and cyclotomic arithmetic.
