# Third-party material

The paper, programs, and generated search data in this folder are distributed under Apache-2.0. No third-party program source is vendored. The following dependencies are installed separately and retain their upstream licenses; this bundle supplies no changes to them.

| Dependency | License and use |
| --- | --- |
| [NumPy](https://numpy.org/doc/stable/license.html) | BSD-3-Clause; array computations in the independent join and controls. |
| [mpmath](https://mpmath.org/doc/current/) | BSD-3-Clause; interval and high-precision arithmetic for cosine enclosures. |
| [OpenSSL](https://www.openssl.org/source/license.html) | Apache-2.0 for OpenSSL 3; the second checker uses its cryptographic digest library for row-set comparisons. |

GCC and its OpenMP runtime are build and execution prerequisites, not redistributed components. The small-order class counts are mathematical data credited to Holzmann, Kharaghani and Tayfeh-Rezaie in the paper. The search programs regenerate the positive controls from the Williamson equations. Cited mathematical methods are implemented separately; no source code from the cited papers is included.
