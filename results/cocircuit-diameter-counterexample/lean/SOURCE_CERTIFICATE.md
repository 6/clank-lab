# Source geometry checking guide

The numerical matrix was read in the pinned Coq-Polyhedra repository,
which attributes the instance to the Matschke–Santos–Weibel construction
and Weibel's data. Allamigeon, Canu and Strub proved the attributed source
polytope's exact diameter in Coq. The later pinned file was not compared
with their original Coq input, MSW Table 1 or Weibel's attachments.
This bundle independently certifies the given numerical instance and its
designated pair's distance 21; its proof does not need the historical
identification or a whole-source diameter theorem. It reuses neither
their Coq proof object nor their vertex/edge certificate. Its vertex,
neighbor, label and integer-potential certificate is checked separately here.

The source facts used in Section 3 of the paper are:

- The complete section has 36,425 vertices and 364,250 edges.
- Each vertex has exactly 20 active row labels, with an invertible active
  system; all other inequalities are strict. These are geometric vertices,
  rather than only a list of candidate points.
- Every geometric edge is covered by the certified neighbor relation.
- The integer potential changes by at most one across every edge. The
  designated vertices, with complementary labels 1–20 and 21–40, have
  potential difference 21. Thus every walk between them has at least
  21 edges. A supplied path attains that length.

The compressed certificate is `data/source-certificate.json.gz.part00`
and `part01`. Concatenate and gzip-decompress them to obtain JSON.
The `vertices` array contains the endpoint coordinates at zero-based
indices 0 and 36424, as named by `endpoints`; `endpoint_path` is the
22-vertex attaining path. These coordinates use the formal chart; rays
are rescaled to the printed section by its positive functional.
The public quick check evaluates both independent geometry
consumers and their semantic corruption controls. At source size these
Python consumers check the listed graph; they do not claim exhaustive
basis enumeration. Geometric completeness is a Lean theorem from the
finite local premises, as mapped below.

| Fact | Exact source and statement |
|---|---|
| Finite local premises | [SourceCertificate.lean](SourceCertificate.lean), `SourceVertexCertificate`: feasible points, injective basis labels, exact active sets and a neighbor for each removed label. Completeness is not an assumed field. |
| Active count and nonsingularity | In that file, `SourceVertexCertificate.active_count` and `basis_nonsingular`. |
| Complete geometric cover | `SourceVertexCertificate.covers_active_labels`, using [SourceCover.lean](SourceCover.lean)'s `certified_list_covers_many_active`; see also `certified_source_regularity`. |
| Every geometric source edge is controlled | [SourceDistance.lean](SourceDistance.lean), `common_edge_is_neighbor`, followed by `potential_edge`. |
| Walk lower bound | In that file, `potential_walk` and `specified_distance_lower_bound`. |
| Concrete complementary source endpoints | [MSWSourceEndpoint.lean](MSWSourceEndpoint.lean), `msw_integral_real_vertices` and `msw_endpoint_of_source_certificate`. |
| Integral finite data to geometric certificate | [IntegerSourceCertificate.lean](IntegerSourceCertificate.lean), `IntegerSourceValid.toCertificate`. |
| Unconditional frozen endpoint | [Proof.lean](Proof.lean) applies `ADKZPricing.Generated.source_frozen_endpoint` and `proposed_endpoint_implies_published`; its actual eight axiom guards are printed there. |

The omitted source modules, including the concrete premises closing these
statements, are regenerated by `checks/bootstrap_kernel.py`. Every output
must match the per-file hashes in `checks/generated-kernel-sha256.json`.
The ordinary small check does not prove the full endpoint. The separate
full replay compiled all 1,264 modules, including all 570 source chunks
and 570 data blocks. See [README.md](README.md) for the full build and
[FORMAL_STATEMENT.md](FORMAL_STATEMENT.md) for its precise scope.

The printed appendix's positive functional differs from the formal chart
witness. Its coefficient identities are checked by the exact written
checker. The written Vandermonde perturbations, the standard real-covector
interpretation as an oriented matroid and the matching 42-edge path are
written mathematics; they are not a claim that Lean checked those printed
perturbations or a distance-equality theorem.

## Binding to the external numerical source

The immutable source is [poly20dim21.ine at revision f8b8ce8](https://github.com/Coq-Polyhedra/Coq-Polyhedra/blob/f8b8ce8ebf2516ea1ee4aa6385435204c04d0b5a/enumeration/test/data/poly20dim21/lrs/poly20dim21.ine).
Its SHA-256 is
`7b26610bd7b1e18e16c01ed83b97068e47ed239f4d4b063d10d88d7428b54436`.
All 840 entries agree, in the same row order, with `data/msw-input.json`
as rational numbers. Each row is scaled by the LCM of its reduced
denominators to give the appendix matrix. The upstream comparison and the
printed-matrix comparison were separately performed; the latter is part
of `check_written_certificate.py --data data --check-paper paper/paper.tex`.
The source inventory also pins the exact bundled input bytes.

For example, from the bundle root, this standard-library comparison checks
the external file and every entry directly:

```python
from fractions import Fraction
from pathlib import Path
from urllib.request import urlopen
import hashlib, json

url = ('https://raw.githubusercontent.com/Coq-Polyhedra/Coq-Polyhedra/'
       'f8b8ce8ebf2516ea1ee4aa6385435204c04d0b5a/'
       'enumeration/test/data/poly20dim21/lrs/poly20dim21.ine')
raw = urlopen(url, timeout=30).read()
assert hashlib.sha256(raw).hexdigest() == (
    '7b26610bd7b1e18e16c01ed83b97068e47ed239f4d4b063d10d88d7428b54436')
lines = raw.decode().splitlines()
start = lines.index('begin')
assert lines[start + 1].split() == ['40', '21', 'rational']
upstream = [list(map(Fraction, row.split()))
            for row in lines[start + 2:start + 42]]
bundled = [[Fraction(x) for x in row]
           for row in json.loads(Path('data/msw-input.json').read_text())]
assert upstream == bundled
print('PASS primary source: all 840 rational entries, same row order.')
```
