# Checking notes

The single entry point is `python3 -I checks/check.py`, run from the result's directory. It needs Python 3.12 or newer, numpy (pinned in `requirements.txt` by version and file hashes) and a C compiler (`cc`, or the one named by `CC`). It compiles `check_table.c` in a temporary directory and runs each program below as a separate process. No program imports another.

## The data

`data/q1890.json` and `data/q5670.json` describe the two quandles of the paper's Theorem 1.1. Each gives, for the blocks $`\mathbb{F}_2^2`$, $`\mathbb{F}_3^3`$, $`\mathbb{F}_5^2`$ and $`\mathbb{F}_7^2`$ of $B$, the matrices `a1`, `a2` and `P` (by rows) and the vector `g0`, together with the claimed order and profile. The group $G$ consists of the affine maps $w \mapsto Tw+v$ with $T$ in the group generated by `a1` and `a2`, and the quandle is the class of $`c_0 = P\circ(w\mapsto w+g_0)`$ under conjugation by $G$, with $`x*y=yxy^{-1}`$. The data are those of the paper's Appendix A. In the order-1890 data the third coordinate of the $`\mathbb{F}_3`$-block is inert, so that both files have the same block sizes. The programs print the quandle's name as `Q'`.

## The four programs

- `check_class.py` (checker A, pure Python) represents affine maps exactly over each $`\mathbb{F}_q`$. It checks that $`c_0`$ normalizes $G$, computes the class $C$ of $`c_0`$ by breadth-first search, computes the cycle type of $`R_{c_0}`$ on $C$, and checks that the right translations by six pseudo-randomly chosen elements of $C$ already act transitively. The seed is the second argument: 3 for order 1890 and 2 for order 5670. With seed 2 the six elements chosen for order 1890 happen to generate an intransitive group, and the checker then reports "not shown connected". It accepts only if order and profile match the data and some cycle length does not divide the longest.
- `build_table.py` (checker B, first part, numpy) rebuilds $C$ independently and writes its full operation table, rejecting any product that falls outside $C$. `check_table.c` (checker B, second part) then checks every quandle axiom on the table: idempotence, that every right translation is a bijection, and right self-distributivity over the triples $(x,y,z)$ with $z$ in a given range. It checks connectedness by the orbit of one element under all right translations, that all right translations have the same cycle type, the profile, and faithfulness (all right translations distinct).
- `check_filipi_group.py` (F1, pure Python) checks Filipi's Conjecture 4.1 literally, at the group level: $`c_0`$ normalizes $G$, so $C$ is closed under conjugation by the group $\langle C\rangle$; the orbit of $`c_0`$ under conjugation by four elements of $C$ is all of $C$; the order of $`c_0`$ is 420 and only $`c_0^0`$ commutes with every element of $C$; and for every $z\in C$ some $`c_0^k`$ with $1\le k\le 210$ commutes with $z$.
- `check_filipi_table.py` (F2, pure Python) reads checker B's table and checks, for every $c\in C$, that $`R_c`$ has no cycle whose length equals the order of $`R_c`$. Since $`c^k z c^{-k} = R_c^k(z)`$, this is the failure of the conclusion of Filipi's conjecture at every $c$.

For both quandles the entry point checks right self-distributivity over all triples of order 1890, and over the triples with $z<100$ of order 5670; `--full` adds all triples of order 5670, in six ranges. Distributivity holds automatically in a conjugation quandle, so this checks the table rather than the mathematics. The tables' SHA-256 digests are printed and compared with the expected ones, so both builds are tied to the same table.

## Corruptions

`corrupt.py` makes three altered inputs from each data file, and the entry point demands that each is rejected for the stated reason:

- `c1`: $`g_0`$ with its $`\mathbb{F}_3`$-component set to zero. The profile then satisfies the conjecture (for order 5670 it is $1^2\ 2^{314}\ 20^{63}\ 28^{45}\ 70^{18}\ 140^{9}$), as the paper's Lemma 3.3 predicts. Checker A rejects it because the profile differs from the data, `check_table` because every length divides the longest, and F1 and F2 because Filipi's condition holds, with a cycle of length 140 equal to the order.
- `c2`: $P$ with the identity as its $`\mathbb{F}_7`$-block. Checker A rejects it because $`c_0`$ no longer normalizes $G$, and `build_table.py` because the class is not closed under the operation.
- `c3`: the table with one entry changed, so that $`R_0`$ is not a bijection; `check_table` rejects it.

## Scope

The programs check Theorem 1.1 and Corollary 1.2 for the two quandles given. They do not check the infinite family of Theorem 1.3, its latin members or Proposition 1.4, which rest on the written proofs. Correctness of the checks relies on the Python and C implementations and their runtimes. There is no Lean formalization.

The quick run takes about 150 CPU-seconds and the run with `--full` about 590 CPU-seconds, each with a peak of about 240 MB.

The paper builds with a standard TeX Live installation: run `pdflatex paper.tex` twice in `paper/`.

## Source access

As of November 5, 2026, no posted work refutes or proves Hayashi's conjecture or Filipi's Conjecture 4.1, as far as we could check. Watanabe's 2019 paper, Rehman's thesis, Kayacan's journal paper and the conjecture chapter of Spaggiari's thesis were read, and the statements cited from them are quoted in the paper. The paper of Kajiwara and Nakayama could not be retrieved (its repository was unavailable); it is credited from its zbMATH summary and from Kayacan's account of it. It proves the conjecture for affine quandles, so it contains no counterexample. Watanabe's 2015 and 2017 papers were not read; they precede the 2019 paper, which still states the conjecture as open. The joint paper of Spaggiari and Bonatto had not been posted.
