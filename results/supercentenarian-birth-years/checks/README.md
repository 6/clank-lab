# Reproducing the counts

From the result folder, run `python3 checks/check.py` for the arithmetic, then `python3 checks/reproduce.py` for a fresh calculation. The latter requires Python 3.10 or later, R with base packages, curl and Poppler's pdftotext. It downloads three inputs into a temporary directory, verifies their SHA-256 digests and removes the downloads and reconstructed CSVs on exit. To use local copies of the same bytes, supply `--inputs DIRECTORY` with the filenames below. The random generator uses the Mersenne-Twister, Inversion and Rejection settings of R. The reference counts were produced with R 4.5.2.

The [Gerontology Research Group](https://grg.org/SC/SCListsTables.html) publishes its validated-age tables with a copyright notice and no stated reuse license. Table A and the individual records stay with the source. This bundle distributes original analysis code and derived counts. S1 is downloaded from the author and used locally by reference. The bundle's license applies to the distributed material.

## What the checks cover

The author’s original input CSV was unavailable for a byte-for-byte comparison. The HTML record numbers must run from 1 to 1,739. The birthplace column supplies the US state. Table 1.01 supplies the “Births” column under “Records on file for entire area,” the second year in each extracted row. S1 supplies the source's US selection, state order and positional split. Its year axis and matrix shape stay fixed under each permutation because the set of national years stays fixed. Passing year indices through the source loop identifies how many times each state-year cell occurs in each side of the split, including R's recycling of shorter rows. The replay checks the observed literal count before using those weights and checks every state total and every frequency in both aggregate files.

`state-counts.csv` records observed counts in each mapped state. New York has zeros in both S1 columns because S1 omits it. `shuffle-counts.csv` records the number of draws for each pair of early and eligible counts, separately for each method. Divide within each pair before ranking. The 250th and 9,750th ordered fractions among 10,000 draws give the reported central interval. Each piece draws 500 permutations using one of the consecutive seeds 20261122 through 20261141. The offline checker also reports the median and the observed percentile, counting half the ties, and marginal 95% binomial rank intervals for the endpoints. The source replay checks that each retained entry scores once for every possible year, verifies the effective cutoff in each area, and repeats the common-window calculation with two post hoc early cutoffs (strictly before registration and through the registration year). A blind reimplementation with independent permutations gave the same observed counts and inclusion decisions.

For the sharp bounds over every reassignment, install NetworkX 3.2.1 and run `python3 checks/reproduce.py --bounds`. The script computes minimum-cost integer flows between registration dates and birth years. A flow preserves both totals. Roster slots sharing an administrative date score identically. To check an attainable fraction `p/q`, minimize or maximize `q × early − p × eligible` and check that the optimum is zero. The smallest feasible denominator is 668.

## Further credits

The [GRG table notes](https://grg.org/SC/SCListsTables.html) already describe the 1890s birth cohorts as earlier in their discovery cycle than those of the 1880s. The Internet Archive preserved the historical table used here. The National Center for Health Statistics compiled the administrative dates. The [US analysis and its supplement](https://doi.org/10.1101/704080) are Saul Justin Newman's. The [August 2019 exchange](https://statmodeling.stat.columbia.edu/2019/08/06/are-supercentenarians-mostly-superfrauds/) records Robert Young's objection, commenter Z's observation about the earlier decline, and Newman's reply. [Austad and Pes](https://doi.org/10.1093/geront/gnaf246) discuss validation evidence for Blue Zones, a separate question.
