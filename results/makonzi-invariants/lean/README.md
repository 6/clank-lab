# Lean proof of Makonzi's kernel equality

This Lake project proves the kernel equality in Brian Makonzi's
Conjecture 5.2 for every triple of arm lengths at least two, over the
complex numbers. The source is *Deformations and Simultaneous Resolution
of Determinantal Surfaces*, [arXiv version 2, Section 5.1](https://arxiv.org/html/2309.02982v2#S5.SS1),
and [the published paper](https://doi.org/10.1093/qmath/haaf044).

The proofs, the Lean formalization and the text were produced by AI models (from OpenAI and Anthropic), working under the author's direction.

Install [elan](https://github.com/leanprover/elan), the Lean toolchain
manager, and Git. From this directory, run:

```sh
lake exe cache get
lake build
```

Elan installs the Lean version in `lean-toolchain`: Lean 4.19.0.
`lake-manifest.json` pins every dependency; mathlib is pinned to
`c44e0c8ee63ca166450922a373c7409c5d26b00b`. The first command obtains
mathlib's public compiled cache. The second compiles all included proof
modules and `Checks.lean`, a default build root. Nothing outside this
directory is required. A build with the dependency cache takes a few minutes.

The principal declarations in `FullProof.lean` are:

```lean
theorem kernel_equality (p : Fin 3 → ℕ) (hp : ∀ i, 2 ≤ p i) :
    RingHom.ker (phi p) = minorIdeal p :=
  le_antisymm (ker_le_minorIdeal p hp) (minorIdeal_le_ker p)

theorem endpoint : Endpoint := kernel_equality
```

These declarations are in namespace `Makonzi`. In `Endpoint.lean`,
the complete proposition is:

```lean
def Endpoint : Prop :=
  ∀ p : Fin 3 → ℕ, (∀ i, 2 ≤ p i) → RingHom.ker (phi p) = minorIdeal p
```

For the mathematical dictionary, number the arms by $i=1,2,3$ and the
edges of arm $i$ by $j=1,\ldots,p_i$. Write

```math
D_i=\prod_{j=1}^{p_i}d_{ij},\qquad
U_i=\prod_{j=1}^{p_i}u_{ij},\qquad
A=\prod_{j=1}^{p_1}v_{1j},\quad
B=\prod_{j=1}^{p_2}v_{2j},\quad
C=\prod_{j=1}^{p_3}v_{3j}.
```

The polynomial source and arrow quotient are

```math
S=\mathbb C[w_1,w_2,w_3,v_{ij}],\qquad
H=\mathbb C[d_{ij},u_{ij}]/(D_1-D_2+D_3).
```

The map sends

```math
w_1\longmapsto D_1U_2,\qquad
w_2\longmapsto D_2U_1,\qquad
w_3\longmapsto -D_2U_3,\qquad
v_{ij}\longmapsto d_{ij}u_{ij},
```

with each image taken in $H$. Its kernel is the ideal of the three
minors, in column order $12,13,23$, of

```math
\begin{pmatrix}w_2&w_3&B\\A&w_3+C&w_1\end{pmatrix}.
```

| Mathematical object | Lean definition or convention |
| --- | --- |

| Length $p_i$ | `p (i - 1)`; the hypothesis is `∀ i, 2 ≤ p i` |
| Edge $j$ on arm $i$ | `Edge p := (i : Fin 3) × Fin (p i)`, with edge value `j - 1` |
| Down and up arrow indices | `Arrow p := Bool × Edge p`; `false` means down, `true` means up |

The three generators of `minorIdeal p` are exactly

```math
w_2(w_3+C)-Aw_3,\qquad w_2w_1-AB,\qquad
w_3w_1-(w_3+C)B.
```

`normalForm p N r a b c` is a coefficient-polynomial constant $r$ plus
three sums of positive powers of $w_1,w_2,w_3$, with coefficients
`a b c : Fin N → CoeffRing p` and exponents `k.val + 1`.
`normalForm_exists` supplies a finite, unbounded existential $N$ for
every source polynomial, modulo the minors; $N=0$ is allowed.
The quotient used for this reduction is `NFQuotient p`, with quotient
map `nfQuot p` and induced coefficient map `nfCoeff p`.

The specialization uses the downward values $(t+C)/t$, $1$, and
$-C/t$ on the first edge of the three arms, respectively, and $1$
on every remaining downward edge. Each upward arrow is its own
coefficient variable divided by the corresponding downward value.
These definitions are `downFirst`, `downValue`, `specializationArrow`,
and `specializationEval`; `psi` is the resulting quotient lift.
Every $v$ retains its coefficient value, and the three $w$ images are
$B(t+C)/t$, $At/(t+C)$, and $t$. `allArmSpecialization` packages
these identities. All denominator and coefficient-injection obligations
are proved. `pure_powers_independent` proves independence of these
positive-power families over any field with nonzero $A,B,C$;
`normalForm_specialization_zero` discharges those conditions for the
coefficient field used here. `ker_le_minorIdeal` then combines this
with the normal form and `minorIdeal_le_ker` to prove the endpoint.

`Checks.lean` checks the endpoint's full quantified type, the rings,
quotient relation, generator images, and minors by definitional equality.
It checks small edge counts, both edges of a length-two arm, the negative
third generator image, the empty normal form, and the smallest allowed
arm triple. The axiom guards are `#guard_msgs in #print axioms` for both
`Makonzi.endpoint` and `Makonzi.kernel_equality`. Each must report exactly
`[propext, Classical.choice, Quot.sound]`. An additional axiom, including
`sorryAx`, fails the build. No compiled evaluation axiom is used.
The Lean kernel and the pinned imported libraries are the trust base;
the commands above use the public mathlib cache rather than rebuilding
all dependencies from source.

`Endpoint.lean`, `Containment.lean`, `Shared.lean`, `NormalForm.lean`,
`Specialization.lean`, `Independence.lean`, and `FullProof.lean` contain
the definitions and complete proof. `Bernstein.lean` contains a separate
polynomial independence lemma, also built, that the endpoint does not use.
The critical-pair identities in `Endpoint.lean` are also retained and
checked; the endpoint does not use them as a confluence theorem.

The formal theorem concerns the arrow quotient $H$ directly. The source
defines its map into an invariant subring of $H$; inclusion of a subring
is injective and therefore preserves the kernel. The torus action, this
invariant-subring identification, and the generation theorem of
Proposition 5.1 are not formalized here. Obtaining the presentation of
the invariant ring also uses that published generation theorem and the
first isomorphism theorem. The endpoint itself has no generation,
primeness, flatness, or nonvanishing hypothesis. Fraction fields occur
inside its proof, with no restriction to nonzero-product fibers in its
statement. The deformation fiber relations of Section 3.3 are not
imposed: the arrow quotient uses only equation (3.A).

The source correspondence uses the kernel wording of Conjecture 5.2
in version 2. Its printed edge range excludes the first edge, whereas
matrix (5.A) and Section 4.3 explicitly include that edge. This
formalization uses every edge, including the first, as those displays
require. The condition $p_i\geq2$ expresses the nonempty arms drawn in
Section 2; it is a translation of that family, not a verbatim printed
inequality. These source interpretations and the invariant-ring bridge
are mathematical readings of the paper, outside the Lean statement.

To typeset the note, install XeLaTeX and the JuliaMono font, then run
`xelatex paper.tex` twice from the accompanying `paper` directory.
The verbatim listings are read from `data` and match the declarations in
this project. Typesetting is separate from checking the mathematical proof.

The source-faithfulness acceptance compared arXiv:2309.02982v2. The
published formulation was also checked in the typeset 18-page Advance
Access article (DOI [10.1093/qmath/haaf044](https://doi.org/10.1093/qmath/haaf044)),
read through Muni University's institutional repository:
the ring is on page 5, the first-edge coordinates on pages 14–15, the map,
matrix (5.1) and Proposition 5.1 on page 16, and the kernel formulation of
Conjecture 5.2 on page 17. These locators are Advance Access page numbers;
the issue-numbered PDF was not read. The strict edge inequality is printed
in the journal copy as well as arXiv v2. Version 1's unquotiented-map
isomorphism wording cannot hold in the presence of the displayed nonzero
minor relations. The paper proves the intended kernel formulation.
